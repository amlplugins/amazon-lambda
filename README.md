# @amlplugins/amazon-lambda

Native `@aws-sdk/client-lambda` SDK re-exported under the `@amlplugins` namespace.

> AWS Lambda — function CRUD, invocation, layers, aliases, event-source mappings, function URLs.

## Install

```bash
npm install @amlplugins/amazon-lambda
```

## Use

```ts
import { /* named exports from @aws-sdk/client-lambda */ } from "@amlplugins/amazon-lambda";
// or
import sdk from "@amlplugins/amazon-lambda";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
